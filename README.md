# 🛒 Canteen Order System

This project is a terminal-based canteen order application developed using Object-Oriented Programming (OOP) principles and core Python concepts. 

Users can view the current canteen menu and place orders for their desired items.

## 🚀 Features

- **View Menu:** Display all products sold in the canteen alongside their prices.
- **Place Order:** Process orders by checking product availability against the menu based on user input.
- **Error Handling:** Notify the user when an item is not found in the menu or when an invalid option is selected.

---

## 🛠️ Concepts Used

- Object-Oriented Programming (Class, `__init__`, Instance Method)
- Data Structures (Dictionary)
- Control Structures (`while` loop, `for` loop, `if-else` conditions)
